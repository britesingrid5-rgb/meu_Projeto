Arquivo de texto explicando como compilar e executar.

1: Em todos os ficheiros da pasta do projeto, aperte Ctrl + s para salvar (se já não estiver salvo).


2: No terminal do vs.code sertifique-se de que o nome da pasta já está no terminal. Se não estiver, no terminal do vs.code digite os seguintes comandos:
cd
 "Para que serve o cd: O cd é o comando para o terminal ir nas pastas do computador. Exemplo: Área de trabalho, Documentos.etc." (Obs: As áspas é para apenas explicar o comando do cd).

cd "local onde está localizado a pasta" (sem as áspas)
Para que serve o cd "local onde está localizado a pasta"
 Exemplo: cd Documentos. Para que serve esse comando: O cd Documentos é o comando para o terminal ir diretamente no local Documentos.

cd "nome da pasta" (sem as áspas)
Para que serve o cd "nome da pasta". Exemplo: cd biblioteca_PC1
Para que serve o comando cd biblioteca_PC1: O comando é para o terminal localizar que é essa pasta que está salvo no local Documentos e assim o terminal entender que é essa pasta que deve executar.

Resumindoos comandos do segundo passo:
cd
cd "local onde a pasta está salva no computador" (sem as áspas).
cd "nome da pasta" (sem as áspas).


3: Ainda no terminal digite make de Makefile. Se o programa não executar com o comando make, digite os seguintes comandos:
gcc *.c -o "o nome como quer chamar o exercício" OU gcc "todos os ficheiros.c -o e o nome como quer chamar o exercicío" (sem as áspas). Obs: o "nome como quer chamar o exercício" é o nome onde foi dado no arquivo Makefile.

./"o nome do exercício" (sem as áspas)
